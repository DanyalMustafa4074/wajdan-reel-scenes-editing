# Reel #15 — "Ek Ghalati Jo NZ Applicants Karte Hain" (StudyPrime)

StudyPrime organic reel + paid-ad variant. New Zealand warning/teaching explainer. Doodle-on-kraft,
StudyPrime navy + gold, warm green for NZ. Roman-Urdu + English. Built with `/REEL-PIPELINE-PLAYBOOK.md`.

- **Angle:** NZ applicants pick a field first (naam/trend), then the university — the wrong order. In
  NZ your **field** decides whether you can settle (PR). The **Green List** is the set of occupations
  with a clear PR route. Fix: check the route first, then pick the field that takes you there.
- **Target audience:** students planning to study in New Zealand.
- **CTA keyword:** "GREENLIST" (Ending 1 — confirm before publishing).
- **Length:** ~60–70s, 9:16. **Two endings** (reel: comment "GREENLIST" · ad: book a free call).
