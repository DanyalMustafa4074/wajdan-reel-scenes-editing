# Study Prime — Content Formula

## Brand
Study Prime (`studyprime.pk`) is a study-abroad advisory. Audience: students (UK/Europe focus) and
their parents. Recurring face on hooks = **Ahsan** (saved **@ahsan** Freepik character).

## Voice
Honest, plan-first, anti-hype, protective. The brand built its reputation warning students against
overselling ("UK is heaven") and bad consultants. Every post should feel like the one honest person
in the room. Casual, plain-spoken, a little contrarian. No corporate fluff.

## The accuracy rule (non-negotiable)
This brand's credibility IS its product. So:
- **Never invent statistics.** No "90% of students…" unless it's a sourced fact. Use qualitative
  wording: "most students", "so many students".
- **Verify volatile facts** (tuition, visa rules, post-study work, PR pathways, scholarship amounts)
  against an official source (gov immigration sites, DAAD, UCAS, university pages) before putting a
  number on a slide. If it can't be verified, soften or cut it.
- Prefer **evergreen advice** topics (mindset, planning, consultant-vetting, application mistakes)
  over fact-heavy ones when speed matters — they carry no factual risk.

## Hook formula (Slide 1 — the user builds the image)
- 2–4 words, UPPERCASE, split navy + ONE gold pop-word.
- Create a curiosity gap or name a mistake. Contrarian beats generic.
- Always give the user **exactly 3 options** and let them pick.
- Examples that worked: `WRONG QUESTION.` · `WHICH COUNTRY?` · `FORGET THE RANKING` ·
  `WRONG ORDER` · `YOUR AGENT IS LYING` · `BEFORE YOU PAY, ASK THIS` · `THIS GETS YOU REJECTED`.

## Slide structure (≤5 slides)
- **S1** hook (image).  **S2** set up the problem / reframe.  **S3–S4** the value (list or steps).
  **S5** CTA.
- Each inner slide: a two-line headline (navy + gold pop) + short body. One idea per slide.
- Lists: keep to ~3 items per slide; for a 6-item list split "First 3 / Next 3" across two slides.
- Headlines short so the gold word fits one line.

## CTA (Slide 5)
Save + Share + book a **1-1 consultation**. On Instagram: "link in bio". On LinkedIn: "link in
comments" (LinkedIn throttles posts with links in the body). Three rows: 🔖 save / ↗ share / 💬
consult, plus the navy "1-1 CONSULTATION — LINK IN BIO" bar.

## LinkedIn caption template (goes in the zip as LinkedIn-Post.txt)
```
<one scroll-stopping first line — the hook as a full sentence>

<the value written out in short lines / a numbered list, so the post delivers even without swiping>

📌 Save this before <moment of need>.
♻️ Repost to help a student <situation>.
💬 Want <the offer>? Book a free 1-1 consultation — link in comments.

#studyabroad #internationalstudents #studyprime <+ 2-3 topic tags>
```

## Standing idea bank (safe / evergreen — no volatile facts)
1. The 3-Year Method — goal first, country last.
2. Rankings Are a Trap — outcomes beat rankings.
3. Course → Country → University — the right priority order.
4. Consultant Red Flags — warning signs.
5. Questions Before You Pay — money/contract questions.
6. Interview Your Consultant — green flags / how to vet a good one.
7. Application Mistakes — what gets you rejected (SOP, finances, timing).
8. Start 12 Months Out — the application timeline.
9. Parents, Read This — questions for the family paying the bill.

Fact-heavy topics (verify every claim first): real cost breakdown, "study almost free" countries,
why student visas get rejected (rules), post-study work + PR by country.
