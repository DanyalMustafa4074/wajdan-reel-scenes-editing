# Reel #11 — "Interview Ka Darr" (StudyPrime)

StudyPrime reassurance reel. English-led / Urdu mix. Doodle-on-kraft style. Built with
`/REEL-PIPELINE-PLAYBOOK.md`.

- **Angle:** Interview fear holds capable students back. Two truths defuse it — (1) New Zealand has
  NO university/embassy interview (just your file + documents); (2) in the UK, even if there is one,
  you get more than one chance. The scary thing is smaller than it looks; info handles the fear.
- **Target audience:** capable students (admission + funds ready) frozen by interview fear.
- **CTA keyword:** "INFO" (per Ending 1 — confirm before publishing).
- **Length:** ~55–70s, 9:16. **Two endings** (reel: save + send + comment "INFO" · ad: book a call).
